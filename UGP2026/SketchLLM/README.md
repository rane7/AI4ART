# SketchLLM

## Project Overview

- Project Title: Interactive Sketch Generation Driven by Large Language Models
- Lead Student: Yuwen Fang
- Expected Completion Time: On or before May 15, 2026

This project explores an interactive sketch generation workflow guided by large language models, with an emphasis on improving controllability and human-computer interaction during the creative process.
