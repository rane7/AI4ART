# DiffStyle

## Project Overview

- Project Title: Image Style Transfer Based on Diffusion Models
- Lead Student: Yan Zou
- Expected Completion Time: On or before May 15, 2026

This project studies image style transfer methods built on diffusion models, aiming to achieve higher-quality style rendering while preserving essential image structure and semantics.
