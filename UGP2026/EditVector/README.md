# EditVector

## Project Overview

- Project Title: Research on Generation Methods for Structured and Editable Vector Graphics
- Lead Student: Qianguan Zhou
- Expected Completion Time: On or before May 15, 2026

This project focuses on generation methods for vector graphics that remain structured and editable, with the goal of supporting downstream design refinement and content reuse.
