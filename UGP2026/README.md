# Undergraduate Graduation Project

This repository contains the source code and experimental resources for the Class of 2026 undergraduate graduation projects.

## Project List

Detailed research content, technical routes, and documentation can be found in the corresponding project folders located in the same directory as this README.

| Lead Student | Project Title | Project Code |
| :--- | :--- | :--- |
| Yuwen Fang | Interactive Sketch Generation Driven by Large Language Models | SketchLLM |
| Yan Zou | Image Style Transfer Based on Diffusion Models | DiffStyle |
| Qianguan Zhou | Research on Generation Methods for Structured and Editable Vector Graphics | EditVector |
| Jinghui Chen | Semantic-Aware Image Inpainting for Complex Missing Regions | SemInpaint |
| Yiyu Li | Digital Image Restoration Methods and Implementation for Murals | MuralRestore |

## Running and Testing

Each project folder contains a ready-to-run `app.py` script.

1. **Environment Setup**: Before running the code, please ensure the required virtual environment for the specific project is configured and activated according to its local instructions.
2. **Data Preparation**: Links to the required datasets or pre-trained weights are provided within each subfolder. Please download and place them in the specified directories.
3. **Execution**: Once the environment and data are prepared, run `python app.py` in the corresponding directory to launch the application and view the results.

# Undergraduate Graduation Project

## 项目列表

各项目的具体研究内容、技术路线及相关文档，请进入本 README 同级目录下的对应项目文件夹中查看。

| 负责人 | 项目名称 | 项目简称 |
| :--- | :--- | :--- |
| 方郁雯 | 大语言模型驱动下的交互式草图生成 | SketchLLM |

对应项目文件夹如下：`SketchLLM`、`DiffStyle`、`EditVector`、`SemInpaint`、`MuralRestore`。

## 运行与测试说明

每个项目文件夹内均设有可直接调用的 `app.py` 文件。

1. **环境配置**：在运行代码前，请务必确保已根据各项目内的说明配置并激活了对应的虚拟环境。
2. **数据准备**：项目运行所需的数据集或预训练权重链接均已在各子文件夹内提供，请提前下载并放置于指定路径。
3. **启动程序**：环境与数据准备完成后，在对应目录下运行 `python app.py` 即可启动并查看程序运行结果。
