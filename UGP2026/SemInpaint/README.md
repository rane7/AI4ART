# SemInpaint

## Project Overview

- Project Title: Semantic-Aware Image Inpainting for Complex Missing Regions
- Lead Student: Jinghui Chen
- Expected Completion Time: On or before May 15, 2026

This project investigates semantic-aware image inpainting methods for complex missing regions, targeting stronger structural coherence and more contextually plausible restoration results.
